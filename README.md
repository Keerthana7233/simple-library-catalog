# Simple Library Catalog System

A simple Python program that manages a library book catalog using classes and basic data structures.

## Features

- Create and represent books using a `Book` class
- Add books to the library catalog
- Prevent duplicate books using ISBN
- Remove books using ISBN
- Search books by title
- Search books by author
- List all books sorted alphabetically by title

## Book Attributes

Each book contains:

- Title
- Author
- Publication year
- ISBN

## Files

- `library_catalog.py` - Main Python program
- `README.md` - Project documentation

## How to Run

Open the terminal in the project folder and run:

```bash
python library_catalog.py
